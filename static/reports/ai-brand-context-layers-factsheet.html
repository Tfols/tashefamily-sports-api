The Six-Piece Context Layer

What a firm's (or power user's) design context layer should contain, at minimum:

  1. 1Frozen, versioned token-of-truth file (W3C-compliant), AI reads but never regenerates
  2. 2Concise, principle-based AI instruction file — dimensions to think about, defaults to avoid, not exhaustive values
  3. 3Component-assembly constraint — AI restricted to real components, never inventing new ones
  4. 4Evaluation/audit loop — linting, screenshot-diff, a short recurring human sync
  5. 5A governance model chosen deliberately, not defaulted to
  6. 6Explicit ownership + semantic-versioning discipline

TIER 1 — Well-Supported

Vendor-primary or independently verified: W3C standard, Anthropic's own Skill docs, Figma's own survey.

TIER 2 — Commercially-Interested, Consistent

Drift/DesignOps analysis from vendors and agencies with a stake, but internally consistent with T1 material.
